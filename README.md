# Notes App

A small command-line notes app built with Node.js. You can add notes, view the list, and delete a note by its number.

## Requirements

- Node.js

## Run

From this directory, run:

```bash
node index.js
```

The app displays a menu:

1. Save a note
2. View saved notes
3. Delete a note by its ID
4. Exit

Notes are written to `notes.json` in the current working directory. Run the app from this project directory so the file is created here.
